# alpha-blog

A small blog built with Ruby on Rails: create, list, show, edit and delete articles, with validations and flash messages.

## Stack

- Ruby 3.4.11, Rails 7.1
- SQLite in development and test, PostgreSQL in production
- Hotwire (Turbo) with import maps, no Node build step
- Bootstrap 5.3 from a CDN, including toasts for flash messages
- Minitest for model and controller tests, RuboCop for linting

## Features

- Articles with a title (6–100 characters) and a description (10–300 characters). Invalid forms show the validation errors.
- Delete with a confirmation dialog.
- Navigation bar with a collapsible menu on small screens.

## Run locally

```
bundle config set --local without production
bundle install
bin/rails db:prepare
bin/rails server
```

Open `http://localhost:3000`.

`without production` skips the `pg` gem, which needs the PostgreSQL client library and is only used in production.

## Tests and lint

```
bin/rails test
bundle exec rubocop
```

RuboCop is configured in `.rubocop.yml`, which excludes the files generated by Rails.

## Deploy

The app is set up for [Render](https://render.com) with `render.yaml`, which defines a free web service and a free PostgreSQL database. The build runs `bin/render-build.sh`, which installs gems, precompiles assets and runs migrations.

Set `RAILS_MASTER_KEY` in Render to the contents of `config/master.key`, which is not in the repository.

On Render's free plan the web service spins down after 15 minutes without traffic (the next visit takes about a minute to wake it up), and the free PostgreSQL database expires 30 days after it is created.
